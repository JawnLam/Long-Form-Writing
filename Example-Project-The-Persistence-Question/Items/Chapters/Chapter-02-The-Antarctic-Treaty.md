# Chapter 2: The Antarctic Treaty

## Purpose

The first detailed worked example. The Antarctic Treaty (1959) is the most institutionally elegant case in the book — explicit, multi-stakeholder, designed-from-scratch, sixty-five years old, still functional. Use it to make the four-conditions framework concrete before the cases get harder.

Key argumentative work:

- Demonstrate that the four conditions can be identified and named in a real case
- Show how the conditions interact (not independent)
- Set up the framework as analytically useful for the chapters to follow
- Distinguish persistence-by-structure from persistence-by-luck or persistence-by-irrelevance
