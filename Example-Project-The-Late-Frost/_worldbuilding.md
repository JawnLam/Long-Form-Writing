# The Late Frost — Worldbuilding (minimal)

> **The Late Frost is contemporary literary realism set in 2026 Sonoma. The world IS the default world; no system-building is required beyond setting-specific notes. This file exists to document that decision; substantive world-rules for this cartridge live in `_continuity.md` (vineyard mechanics, frost biology, family-rules) rather than here.**

## What this world is

Contemporary Sonoma Valley, California. April 2026. Late-frost season threatening estate vineyards in the Glen Ellen AVA. The world is the default — present-day rules apply.

## Why this file is minimal

Per chapter 15 §1 of the engine, `_worldbuilding.md` is required for SFF / fantasy / speculative / alt-history / horror cartridges. For contemporary realism it is not required; including it here is the shipped-example demonstration of *what a minimal worldbuilding file looks like for a cartridge that doesn't need substantive worldbuilding.*

If the writer were to expand The Late Frost into, say, a speculative variant (an alt-2026 with climate-displacement-driven extreme weather events that have reshaped California wine country fundamentally), `_worldbuilding.md` would expand to cover the climate-history, the political response, the displaced communities, the changed economy. That isn't this manuscript.

## What lives in `_continuity.md` instead

For The Late Frost, the substantive system-knowledge lives in `_continuity.md`:

- Vineyard mechanics (Cabernet / Zinfandel / Sauvignon Blanc plantings; estate scale; production levels)
- Frost biology (28°F threshold; 3-hour exposure window; primary vs secondary bud mechanics; 10-day assessment lag)
- Frost-defense equipment (wind machines, propane heaters, smudge pots)
- Hollis family rules (mother's death 1998, father's death 2025, the estate)
- The Mendel-letter information state

This is the right distribution for contemporary realism. Worldbuilding-as-procrastination (F45) is the risk this cartridge is structurally protected from.

## When this file would expand

- If sub-genre changed to `speculative` or `historical`
- If the world's economic, climatic, or political defaults were displaced from contemporary reality
- If the prose were investing substantial time in establishing the world (rather than the world being assumed)

For now: this file is a one-page placeholder documenting the choice not to expand it.
