# <Manuscript Title> — Save the Cat Overlay

> **Blake Snyder's fifteen-beat sheet (originally for screenplays, since adapted to novels). Commercial fiction; thriller / mystery / romance / YA / SFF. Reading lens — not a prescription. If the spine doesn't fit, the overlay is wrong for this manuscript.**

## The fifteen beats

For a novel of ~80,000 words, beats land approximately at the percentages noted. Use the percentage as a *targeting cue*, not as a rule.

| # | Beat | Approx % | Scene(s) | Notes |
|---|------|----------|----------|-------|
| 1 | **Opening Image** | 0–1% | | The "before" — what the world looks like before the story acts |
| 2 | **Theme Stated** | 5% | | A character states the theme (often without recognizing it) |
| 3 | **Set-Up** | 1–10% | | Introduce the protagonist's world, supporting cast, and the cracks in the status quo |
| 4 | **Catalyst** | 10% | | The event that disrupts the status quo |
| 5 | **Debate** | 10–20% | | The protagonist resists; the call is real but not yet accepted |
| 6 | **Break Into Act Two** | 20% | | The protagonist enters the upside-down world |
| 7 | **B Story** | 22% | | A relationship subplot begins (often the carrier of theme) |
| 8 | **Fun and Games** | 20–50% | | The premise's promise delivered — what the back-cover sold |
| 9 | **Midpoint** | 50% | | A false win or false loss; stakes raised; the real stakes become visible |
| 10 | **Bad Guys Close In** | 50–75% | | Forces (external + internal) press on the protagonist |
| 11 | **All Is Lost** | 75% | | The lowest point; often a death (literal or symbolic) |
| 12 | **Dark Night of the Soul** | 75–80% | | The protagonist confronts what's been lost; the change-decision forms |
| 13 | **Break Into Act Three** | 80% | | The new approach; a-story and b-story synthesize |
| 14 | **Finale** | 80–99% | | The action that resolves the dramatic question |
| 15 | **Final Image** | 99–100% | | The "after" — mirrors the Opening Image with the change shown |

## Divergence notes

*Where this manuscript deliberately doesn't fit. Literary fiction often refuses the "false win at the Midpoint" structure; a romance may compress the Bad Guys / All Is Lost. Document deliberate divergence.*

## Risks

- **Treating fifteen beats as a checklist.** The most-weaponized overlay; most-criticized as a formula. Resist.
- **Forcing beat-positioning at the % level.** Story telling is not a sine wave; close fit is often a tell that the writer is hitting marks rather than serving the work.
- **Theme-Stated as on-the-nose.** Beat 2 frequently produces F42 (on-the-nose theme) when misapplied. Have a character mention something related; don't state the thesis.

## How to use this overlay

- During OUTLINE on a commercial-fiction cartridge: check that the major turning points (Catalyst, Midpoint, All Is Lost, Finale) are present
- During READ-THROUGH: audit Act One's length (Act One past 25% is a red flag for commercial pacing)
- During REVISE: when a section feels slow, check whether you're between beats and the rhythm has gone slack
