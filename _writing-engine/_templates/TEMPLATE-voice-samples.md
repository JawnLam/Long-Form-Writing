## How this file is used

The AI reads this file at session start when voice mode is enabled. It uses these samples to:

- Calibrate offered drafts in DRAFT mode (offer prose that sounds like *this writer*)
- Flag voice inconsistencies in REVISE mode
- Run VOICE-CHECK passes against drafted sections

The AI does NOT use these to "average" the writer's voice or impose a style. Samples calibrate; they don't homogenize.
