# <Manuscript Title> — Hero's Journey Overlay

> **Joseph Campbell's monomyth, distilled by Christopher Vogler. Twelve stages. Best fit: mythic / fantasy / quest / sci-fi / coming-of-age structures. A reading lens; not a prescription.**

## The twelve stages

| # | Stage | Question | Scene(s) | Notes |
|---|-------|----------|----------|-------|
| 1 | **Ordinary World** | What is the hero's life before the call? | | |
| 2 | **Call to Adventure** | What disrupts the ordinary world? | | |
| 3 | **Refusal of the Call** | Why does the hero resist? | | |
| 4 | **Meeting the Mentor** | Who provides knowledge / aid? | | Mentor may be human, object, knowledge — not always a wise-elder |
| 5 | **Crossing the Threshold** | What commits the hero to the journey? | | |
| 6 | **Tests, Allies, Enemies** | How is the hero formed by the new world? | | |
| 7 | **Approach to the Inmost Cave** | What preparation precedes the central ordeal? | | |
| 8 | **Ordeal** | What near-death (literal or symbolic) does the hero face? | | |
| 9 | **Reward (Seizing the Sword)** | What does the hero gain from surviving? | | |
| 10 | **The Road Back** | What pulls the hero toward home? | | |
| 11 | **Resurrection** | What final confrontation tests the hero's transformation? | | |
| 12 | **Return with the Elixir** | What does the hero bring back to the ordinary world? | | |

## Divergence notes

*Where this manuscript deliberately departs from the monomyth. Modern fantasy often refuses the Resurrection stage; literary fiction often refuses the Return with the Elixir (the hero doesn't bring anything back; the question of what they "gained" is left open). Document deliberate divergence.*

## Risks

- **Treating the journey as a costume.** The mythic resonance is powerful when it surfaces from the story; it is hollow when applied as an overlay-after-the-fact.
- **Mentor-as-trope.** Stage 4 is the most-clichéd; the mentor figure in modern fiction is often more honest as a fragment, a memory, an object.
- **Resurrection-as-finale-spectacle.** Stage 11 often inflates into a final battle that crowds out the actual transformation.

## How to use this overlay

- During OUTLINE on a fantasy / SFF / mythic cartridge: check whether the journey shape supports the story or fights it
- During READ-THROUGH: identify stages that are structurally present but emotionally absent (the most common defect)
- During REVISE: when a section feels mythic-empty, identify which stage it should be carrying
